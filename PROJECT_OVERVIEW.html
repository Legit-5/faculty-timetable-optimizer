Faculty Timetable Optimizer

An intelligent, conflict-free scheduling engine designed to automate college & university class timetables with fair faculty workload distribution.

🌟 1. Project Introduction

The Faculty Timetable Optimizer eliminates manual timetable clashes by automating the mapping of teachers, subjects, days, and time slots into an optimized weekly schedule.

🛡️ Conflict Prevention

Ensures no teacher is assigned to multiple classes simultaneously in the same time slot.

⚖️ Fair Distribution

Equally rotates subjects and teachers across days using cyclic round-robin distribution.

📊 Real-time Analytics

Tracks scheduled vs. required teaching hours per subject with live progress indicators.

🧠 2. Algorithm Architecture

The scheduling engine uses a Greedy Round-Robin Algorithm with Constraint Satisfaction.

  • Step 1: Input Ingestion
    Accepts arrays for Faculty list, Subject list, Days of the week, and custom Time Slots.
  • Step 2: Schedule State Tracker
    Creates a hash map faculty_schedule = { teacher: [] } to store all assigned (Day, TimeSlot) tuples per faculty member.
  • Step 3: Nested Day & Slot Traversal
    Iterates sequentially through each Day, and within each Day, through every Time Slot.
  • Step 4: Round-Robin Pick
    Picks the next Subject with subject_index % len(subjects) and next Teacher with faculty_index % len(faculty).
  • Step 5: Conflict Avoidance & Greedy Shifting
    Checks if the chosen teacher already has a class in that (Day, Slot). If busy, the pointer immediately advances to the next available teacher.
  • Step 6: Slot Assignment & Pointer Step
    Appends the class to the timetable, logs the booking in faculty_schedule, and increments pointers for the next round.

💻 3. Python Implementation (app.py)

def generate_timetable(faculty, subjects, days, time_slots):
    timetable = {}
    
    # Tracks occupied (day, slot) per teacher
    faculty_schedule = {teacher: [] for teacher in faculty}

    subject_index = 0
    faculty_index = 0

    for day in days:
        timetable[day] = []

        for slot in time_slots:
            subject = subjects[subject_index]
            teacher = faculty[faculty_index]

            # Conflict check: shift to next teacher if busy
            if (day, slot) in faculty_schedule[teacher]:
                faculty_index = (faculty_index + 1) % len(faculty)
                teacher = faculty[faculty_index]

            # Assign lecture slot
            timetable[day].append({
                "time": slot,
                "subject": subject,
                "faculty": teacher
            })

            # Book the slot & advance round-robin pointers
            faculty_schedule[teacher].append((day, slot))
            subject_index = (subject_index + 1) % len(subjects)
            faculty_index = (faculty_index + 1) % len(faculty)

    return timetable
